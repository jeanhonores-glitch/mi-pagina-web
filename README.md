 Nexus Game Store

 Descripción del proyecto

Nexus Game Store es una página web de temática gamer diseñada para presentar videojuegos, destacar ofertas y mostrar próximos lanzamientos. Cuenta con una interfaz moderna, colores neón y un diseño adaptable a diferentes tamaños de pantalla.

 Características principales

Inicio: presentación de la tienda y enlaces a plataformas de videojuegos.

Juegos populares: sección con imágenes y enlaces a diferentes plataformas.

Productos destacados: catálogo de videojuegos con descripciones y precios.

Ofertas especiales: sección de juegos con descuentos promocionales.

Próximos lanzamientos: muestra videojuegos y permite abrir un formulario para solicitar notificaciones.

Top ventas: listado de videojuegos destacados.

Más contenido: espacios para agregar nuevas categorías y funcionalidades.

Suscripción: formulario para ingresar un correo electrónico.

Notificaciones interactivas: mensajes visuales para informar al usuario sobre diferentes acciones.

Diseño adaptable: menú de navegación y distribución de productos adaptados a dispositivos móviles.
